# PrestoSoft

We make file and folder comparison tools for Windows and the web, developed by the same author since 1997.

![ExamDiff Pro comparing two C++ files side by side](https://www.prestosoft.com/images/screenshots/edp_feat_files.png)

## Products

- **[ExamDiff Pro](https://www.prestosoft.com/edp_examdiffpro.asp?ref=github)**: visual file and folder comparison and merge for Windows. It has code-aware syntax highlighting and structure matching, compares Word, Excel, PowerPoint, PDF, and Zip files, and does 2- and 3-way merge, also as a Git merge tool. Native x64, Win32, and ARM64 builds. Free 30-day trial.
- **[ExamDiff](https://www.prestosoft.com/edp_examdiff.asp?ref=github)**: a free, lightweight tool for comparing two text files side by side.
- **[DiffNow](https://www.diffnow.com/?ref=github)**: compare files, folders, URLs, and text online, powered by ExamDiff Pro.

## Repositories

- **[examdiff-git-config](https://github.com/PrestoSoft/examdiff-git-config)**: set up ExamDiff Pro as the diff and merge tool for Git.

## Official downloads

ExamDiff Pro and ExamDiff are distributed only from [prestosoft.com](https://www.prestosoft.com/edp_download.asp?ref=github). Repositories elsewhere on GitHub that offer "full versions", keys, or patches for ExamDiff Pro are not ours and may contain malware.
